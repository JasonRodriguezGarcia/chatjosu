## Entre Amigas · Te orienta — Product Identity

### Naming

Technical name:

Copilot ONG / HelpChat

Public name:

Entre Amigas · Te orienta

Attribution:

Una iniciativa de Entre Amigas Anda la Cosa

The technical name should normally remain invisible to end users.

### Brand Relationship

The product is an initiative associated with Entre Amigas Anda la Cosa.

The interface should inherit the warmth and conversational character of that project without reproducing the visual language of a YouTube thumbnail inside an application.

The application is a practical orientation service, not a promotional page for the channel.

### Visual Direction

The existing public identity uses energetic yellow, mint/green, coral/red, dark linework, and illustrated human figures.

For the application, those cues are softened into a calmer interface suited to potentially sensitive conversations.

The palette below is an interface adaptation and is not intended to declare exact official brand colour specifications.

### Colour Roles

Warm background should replace large expanses of pure white.

White remains available for conversation surfaces and future resource cards.

Primary plum is the main interaction colour and can identify user messages and primary actions.

Coral and yellow are accent colours and should be used sparingly.

Mint connects the interface to the existing visual identity and is suitable for gentle contextual elements.

Functional green is reserved for resource/context cues where stronger readable contrast is needed.

Colour must never be the only indication of state.

### Interaction Character

The product should feel supportive without pretending to be a human friend.

Warmth must come from clarity, language, spacing, colour, and considerate interaction.

Do not use infantilising illustration, excessive cheerfulness, or decorative elements that trivialise illness, grief, social vulnerability, or family problems.

### Layout Identity

The header should prioritise:

Entre Amigas · Te orienta

A short orientation descriptor may appear beneath or alongside it.

The attribution to Entre Amigas Anda la Cosa should remain subtle.

Location should appear as context, for example:

📍 A Coruña · Cambiar

The initial screen should offer conversational starting points without resembling a questionnaire.

Future association cards should be introduced as resources that may orient the user rather than as exhaustive search results.

### Accessibility Direction

Accessibility is a product requirement rather than a separate visual mode.

The default interface must provide sufficient contrast, semantic controls, visible focus states, keyboard operation, meaningful labels, and screen-reader-compatible status announcements.

Do not communicate meaning through colour alone.

Respect relevant operating-system and browser accessibility preferences where practical.

A future appearance control may provide:

normal;
high contrast;
dark.

The appearance control must complement, not replace, an accessible default interface.

Screen-reader support must not depend on the selected visual theme.

The UI should remain usable with increased browser text size and zoom without requiring horizontal scrolling at normal mobile breakpoints.

Animations and motion should remain restrained and should respect reduced-motion preferences.

A dedicated accessibility/appearance control is intentionally deferred until the core conversation and structured-resource interfaces are stable.
